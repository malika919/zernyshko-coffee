# Зернышко — сайт кофейни

Одностраничный сайт кофейни с формой бронирования столиков.

## 🔗 Демо
Посмотреть сайт: zernyshko-coffee.netlify.app

## 📎 Портфолио
[Посмотреть все работы](https://your-finances.tilda.ws)

## 📋 Что реализовано
- Гибкая вёрстка (flex-wrap)
- Меню с фильтрацией: кофе / десерты / закуски
- Форма бронирования с валидацией полей
- Отправка данных в Google Sheets
- Модальное окно подтверждения отправки
- Плавный скролл по секциям

## 🛠️ Технологии
- HTML5
- CSS3 (Flexbox)
- JavaScript (ES6)
- Bootstrap 5
- Google Apps Script (для отправки формы)

## 📁 Структура
- `index.html` — основная страница
- `style.css` — стили
- `script.js` — логика
- `images/` — изображения
